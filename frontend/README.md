# Frontend

React + Vite. Как запускать весь проект, написано в `../README.md`.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Адреса сервисов лежат в `.env.example`. Если они отличаются от стандартных, скопируй файл в `.env` и поправь.

Команды: `npm run build`, `npm run lint`, `npm run preview`.
